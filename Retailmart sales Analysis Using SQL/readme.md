# 🛒 RetailMart Sales Analysis

A SQL-based analysis of RetailMart sales data to explore customer behavior, product performance, order trends, and revenue generation using MySQL.

## 📌 Project Overview

This project involves importing RetailMart data from CSV files into MySQL, performing data analysis using SQL queries, and extracting meaningful business insights.

## 🗂️ Dataset

The project includes multiple CSV files containing RetailMart business data, which were imported into MySQL for analysis.

## 🔍 SQL Concepts Used

* SELECT & filtering
* Aggregate Functions
* GROUP BY & HAVING
* ORDER BY
* INNER & LEFT JOIN
* Subqueries
* Self Join
* CROSS JOIN
* Conditional expressions
* Date functions
* Revenue & sales calculations

## 📊 Key Analysis

* Customer and order analysis
* Product and category performance
* Revenue analysis
* Employee and order analysis
* Identification of customers with no orders
* Comparison of customer order patterns
* Business insights using SQL queries

## 🛠️ Tools & Technologies

**Database:** MySQL
**Data Source:** CSV
**Analysis:** SQL
